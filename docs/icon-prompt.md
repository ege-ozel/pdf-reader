# App icon prompt (for ChatGPT image generation)

Design a modern, minimal app icon for a lightweight PDF and Word document reader called "PDF Reader".

- Concept: one clean sheet of paper with a folded top-right corner, with a subtle bookmark ribbon (or a small open-book hint) so it reads as "reading", not "editing". Avoid the Adobe Acrobat look: no red, no stylised "A", no PDF letters.
- Style: flat with a gentle depth (soft inner shadow, one subtle highlight), rounded geometry, 2 to 3 colours only. Palette: deep charcoal/ink blue background tone (#1E2330) with a warm amber/orange accent (#E0A052) for the ribbon or fold, and off-white (#F4F1EA) for the paper.
- Composition: a single centred symbol that fills about 60% of the canvas, with generous padding so it survives Android adaptive-icon masking (circle, squircle, rounded square). Keep everything inside the central safe zone (about 66%).
- Must stay recognisable at 48x48 px: no thin lines, no tiny text, no gradients that turn muddy when small.
- Deliver two versions: (1) the symbol only on a TRANSPARENT background, 1024x1024 PNG (the Android adaptive foreground); (2) the same symbol on a solid #1E2330 rounded-square background, 1024x1024 PNG.
- No text, no watermark, no mockup, no phone frame, no shadow outside the icon.
